# 📂 02 - File Organizer

Organiza automáticamente cualquier carpeta clasificando los archivos según su extensión.

En lugar de mover archivos manualmente, la aplicación analiza la carpeta seleccionada, muestra una vista previa de los cambios y solicita confirmación antes de realizar cualquier modificación.

---

## 🎥 Demo

Ver demostración: demo\AUTOMATION LAB 1.mp4

---

## ✨ Características

- 📁 Selección de cualquier carpeta.
- 👀 Vista previa antes de mover archivos.
- ✅ Confirmación antes de aplicar cambios.
- 📂 Clasificación automática por tipo de archivo.
- 🛡️ Evita sobrescribir archivos existentes.
- 🖥️ Interfaz gráfica desarrollada con Tkinter.

---

## 📦 Categorías soportadas

- 📄 Documentos
- 🖼️ Imágenes
- 🎥 Videos
- 🎵 Audio
- 📦 Comprimidos
- 💻 Programas
- 📁 Otros

---

## 🚀 Uso

Ejecutar:

```bash
python app.py
```

Seleccionar la carpeta.

Revisar la vista previa.

Aceptar para organizar los archivos.

O simplemente doble click en el .exe que se encuentra en dist\OrganizadorArchivos.exe
