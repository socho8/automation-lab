# 🔄 03 - Universal File Converter

Convierte archivos entre distintos formatos desde una interfaz web simple e intuitiva.

Este proyecto forma parte de **Automation Lab**, una colección de automatizaciones desarrolladas con Python para resolver problemas cotidianos mediante herramientas prácticas y fáciles de usar.

## ✨ Características

- 🖼️ Conversión de **PNG ↔ JPG**
- 📊 Conversión de **CSV ↔  Excel (.xlsx)**
- 📑 Conversión de **DOCX → PDF** *(requiere LibreOffice)*
- 👀 Vista previa de imágenes convertidas.
- 📥 Descarga inmediata del archivo convertido.
- 📏 Comparación del tamaño original y convertido.
- ⚡ Interfaz web desarrollada con Streamlit.

---

## 📸 Funcionalidades

### 🖼️ Conversión de imágenes

- PNG ↔ JPG
- Vista previa del resultado.
- Comparación del tamaño antes y después de la conversión.

---

### 📊 Conversión de hojas de cálculo

- CSV → Excel
- Excel → CSV

Conservando la estructura de los datos.

---

### 📄 Conversión de documentos

Convierte archivos DOCX a PDF utilizando LibreOffice en modo headless.

## 📚 Lo que aprendí

Durante este proyecto trabajé con una interfaz web utilizando **Streamlit**, además de integrar distintas librerías para procesar imágenes, hojas de cálculo y documentos desde una única aplicación.

También aprendí a gestionar archivos en memoria con `BytesIO`, generar descargas dinámicas y manejar dependencias externas como LibreOffice para determinadas conversiones.
